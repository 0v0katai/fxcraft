This is the fxSDK port of [3D Minecraft by 010ello010](https://www.cemetech.net/forum/viewtopic.php?t=19552). Source code is slightly modified to support compiling for [Add-in Push](https://github.com/0v0katai/Add-in_Push) and fx-CG100.

Build this game by `fxsdk build-cg -c -DPLATFORM=cg && fxsdk build-cg`. If you want to target fx-CG100 instead, use `-DPLATFORM=cw`. Then, copy the entire `assets` folder to the `fxcraft` folder of the calculator storage to use the default and/or festive texture pack.
